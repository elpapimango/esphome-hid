## Microsoft HID reference samples

The LampArray support in `components/hid_lamp_array/` and `components/hid_composite/`
is derived from two MIT-licensed Microsoft reference implementations:

- [microsoft/ArduinoHidForWindows](https://github.com/microsoft/ArduinoHidForWindows) —
  the 292-byte LampArray HID report descriptor in `lamp_array_core.h` was transcribed
  from `src/LampArrayReportDescriptor.h` (itself generated by
  [WaratahCmd.exe](https://github.com/microsoft/hidtools) against HID Usage Tables 1.4),
  and the report state machine follows `src/Microsoft_HidLampArray.cpp`.
- [microsoft/RP2040MacropadHidSample](https://github.com/microsoft/RP2040MacropadHidSample) —
  the TinyUSB feature-report dispatch and the packed report structs follow
  `src/Lighting/LampArray.c` and `src/Lighting/LampArrayHidStructs.h`.
